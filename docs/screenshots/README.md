# GitHub Copilot screenshots

These screenshots show the built management center running in Microsoft Edge with synthetic account and quota responses. The device code and account details are demonstration data.

- `github-copilot-login.png`: device authorization with a copyable code.
- `github-copilot-quota.png`: allowance used, remaining quota, unlimited quotas, and reset date.
- `github-copilot-mobile.png`: the quota card at a 390px viewport.

Browser checks covered device-code copying, successful authorization, quota loading, recovery after a failed refresh, and mobile overflow. These fixtures do not establish that a live Copilot account has authorized successfully.

The Copilot icon comes from [Primer Octicons](https://github.com/primer/octicons/blob/main/icons/copilot-16.svg), distributed under the [MIT license](https://github.com/primer/octicons/blob/main/LICENSE).
